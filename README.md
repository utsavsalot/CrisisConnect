# 🚨 About CrisisConnect

**CrisisConnect** is a full-stack emergency assistance response platform designed to connect people in urgent need with nearby responders, NGOs, and available resources.

During emergencies, people often struggle to find the right assistance quickly. CrisisConnect provides a centralized platform where emergency requests can be created, prioritized, matched with responders, tracked, and resolved.

The platform supports emergency needs such as:

- 🩸 Blood
- 💊 Medicine
- 🏥 Medical Assistance
- 🍱 Food
- 🏠 Shelter
- 🚗 Transportation
- 🚑 Rescue
- 💧 Water
- 🆘 Other Emergency Assistance

The system combines emergency prioritization, location-based assistance, responder availability, NGO resources, communication, notifications, and escalation into a single platform.

---

# ❗ Problem Statement

During emergencies and disasters, assistance can become difficult to coordinate because:

- People may not know where to request help.
- Emergency requests can remain unnoticed.
- Available responders may not know about nearby requests.
- NGOs may have resources but lack visibility into active needs.
- Emergency situations can become more critical while waiting.
- Multiple organizations may respond to the same request.
- Communication between victims and responders can become fragmented.
- Resource availability can change rapidly.

A system is needed to improve the coordination between:

**People → Responders → NGOs → Emergency Resources**

---

# 💡 Our Solution

CrisisConnect creates a unified emergency response ecosystem.

A person can create an emergency request with:

- Emergency category
- Description
- Current location
- Number of people affected
- Medical severity
- Additional information

The system then processes the request through the **Crisis Priority Engine** and makes it available to appropriate responders and NGOs.

Responders can:

- Enable responder mode
- View nearby emergency requests
- Filter requests
- Accept requests
- Navigate to the emergency location
- Communicate with the requester
- Complete the assistance

NGOs can:

- Monitor emergency requests
- Accept/claim emergencies
- Manage resources
- Track active assistance
- View emergencies on a live map
